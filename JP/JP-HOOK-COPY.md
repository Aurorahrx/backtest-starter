## 3-A Zenn 版（技術解説文・自足型）

**タイトル：** `100行で動く「最小の正直なバックテスト」を作った——未来関数なし・手数料込み`

**本文（发布时把 [リポジトリURL] 换成真实链接）：**

```
利益スクショだけ流れてくるTLに疲れたので、逆張りの小さなツールを作りました。
単一ファイル（100行）のPythonスクリプトで、2022–2026年のBTC日足データ
（同梱）に対してSMA 50/200クロスを回し、指標表とエクイティカーブを出力します。

「正直さ」は設計で担保しました。初心者が最初に踏む2つの罠をコードに焼き込みます。

1. 未来関数なし——t日終値のシグナルはt+1日から有効
2. 手数料込み——ポジション変更ごとに10bpsを課金

実行は1コマンド:

```python
python mini_backtest.py
```

Python 3.10+とnumpy/pandasのみ。APIキー不要、オフラインで動きます。

サンプル実行の結果は皮肉なもので、SMA 50/200はBTC買い持ちに勝ちます
（+91.1% vs +69.2%、ドローダウンは半減）——ただし最大ドローダウンは
まだ-39.6%。「勝ってるけど痛い」この張力こそがクオンツの入り口だと
思います。FAST/SLOW/COST_BPSを書き換えて、結論がどうひっくり返るか
試してみてください。手数料を上げただけで「良い戦略」が死ぬ瞬間が、
無料で学べる一番の教訓です。

ソースとデータはGitHubに置いてあります（自作のツールです）:
[リポジトリURL]

※本ツールは教育目的であり投資助言ではありません。過去の成績は
将来の結果を保証せず、収益を保証するものではありません。
```

## 3-B Qiita 版（教程体・不提付费・0 句導流語）

**タイトル：** `Pythonで「未来関数なし・手数料込み」のバックテストを100行で書く`

**正文结构（按此顺序成稿）：**

```
はじめに
バックテストで一番多い失敗は「未来関数」と「手数料ゼロ前提」。
本記事では両方を防ぐ最小実装を100行で解説します。動作確認済みの
コードとサンプルデータ（2022–2026 BTC日足）はGitHubにあります。

環境構築
Python 3.10+ / pip install numpy pandas
（コードブロック）

データ
2022–2026 BTC/USD日足（Yahoo Finance由来・同梱CSV）
1行目から5行目を表示して列構成を説明

実装解説（核心部分，逐步贴代码）
1. シグナル算出 → 翌バー適用（shiftの1行で未来関数を排除）
2. ポジション変更ごとに10bps控除（turnover×コスト）
3. 指標表：リターン/CAGR/Sharpe/最大DD/ボラティリティ/エクスポージャー
4. 買い持ちとの比較（同じ期間・同じ初期資金）

実行結果
サンプル実行の表（+91.1%/-39.6% vs +69.2%/-66.7%）を貼り、
「勝っているのに痛い」を数値で確認

パラメータを変えてみる
FAST/SLOW/COST_BPSを変えると結論が反転する様子を2例ほど
（手数料を20bpsに上げただけでSharpeがどうなるか等）

まとめ
「良い戦略」はコストで死ぬ。検証の型を持つことが最初の一歩。

（最後に1行だけ）
全コードは GitHub リポジトリ「P1-backtest-starter」にあります（自作のツールです）。
※本記事は教育目的であり投資助言ではありません。
```
