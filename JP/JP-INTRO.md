## タイトル
**Backtest in 100 Lines（無料）** —— 100行で動く「最小の正直なバックテスト」

## サブタイトル
未来関数なし・手数料込みを**設計で**担保した単一ファイルのPythonスクリプト。2022–2026年のBTC日足データ（同梱）付き。1コマンドで最初の「信頼できる数字」を出せます。

## これは何か
利益スクショだけが流れてくるTLへの逆張りツールです。初心者が最初に踏む2つの罠を、コードに焼き込みました：

1. **未来関数なし** —— t日終値のシグナルはt+1日から有効（look-ahead bias 排除）
2. **手数料込み** —— ポジション変更ごとに10bpsを課金

実行は1コマンド：

```python
python mini_backtest.py
```

Python 3.10+ と numpy / pandas のみ。APIキー不要・オフライン動作・登録不要。
指標表（リターン / CAGR / Sharpe / 最大ドローダウン / ボラティリティ / エクスポージャー）、
買い持ちとの比較、エクイティカーブ（matplotlib があれば）を出力します。

## 3つのポイント
1. **3分で動く**：同梱のBTC日足データ（2022–2026、Yahoo Finance由来）で即実行。アカウント登録もAPIキーも不要。
2. **コード＝教材**：全行コメント付き。`FAST` / `SLOW` / `COST_BPS` を書き換えるだけで、「良い戦略」が手数料で死ぬ瞬間を無料で体験できます。
3. **付録：LLM用プロンプト10本**：仮説生成・反対意見・過学習チェックなど、最初の一歩をAIと一緒に踏むためのプロンプト集（`prompts/starter_prompts.md`）。

## サンプル実行の結果（2022–2026、10bpsコスト）
| 指標 | SMA 50/200 | 買い持ち |
| --- | --- | --- |
| 総リターン | +91.1% | +69.2% |
| 最大ドローダウン | -39.6% | -66.7% |
| Sharpe (rf=0) | 0.57 | 0.47 |

このサンプルでは買い持ちに勝ち、ドローダウンも半減——ただし最大DDはまだ -39.6%。
「勝っているのに痛い」この張力こそ、クオンツ研究の入り口です。本ツールは戦略の
推奨ではなく、**検証のハーネス（型）**です。
